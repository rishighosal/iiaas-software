# IIAAS Field Monitor — User Manual

**Version:** 1.0 (feat/dashboard-alerts)
**System:** Intelligent Irrigation & Agriculture Automation System

---

## 1. What IIAAS Does

IIAAS collects data from two ESP32 sensor nodes in the field, stores it on a Raspberry Pi (or laptop), and shows it in a web dashboard that you can open on any phone, tablet, or computer on the same Wi-Fi network.

- **Node 1** measures air temperature, humidity, soil moisture, water tank level, and controls the pump relay.
- **Node 2** measures soil temperature, soil moisture, pH, and nutrient levels (Nitrogen, Phosphorus, Potassium).

The system works **entirely offline** — no internet connection or cloud account is required.

---

## 2. Starting the System

### 2.1 Start the Server

```bash
# On the Raspberry Pi or laptop that is connected to the field Wi-Fi
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

The dashboard is then available at:
- **On the same machine:** `http://localhost:8000`
- **From your phone / tablet:** `http://<pi-ip-address>:8000`

### 2.2 Connect a Data Source

Use **only one** data source at a time:

| Source | Command | When to Use |
|--------|---------|-------------|
| Simulator (Demo mode) | `python tools/simulator.py --scenario <name>` | Software-only demonstration without hardware |
| Wi-Fi Hub (real ESP32) | `python receiver/hub_poller.py --hub http://<hub-ip>` | Live field data via existing hub |
| LoRa USB (Wio-E5) | `python receiver/serial_receiver.py --port /dev/ttyACM0 --init` | Future LoRa prototype |

**Demo Simulator Scenarios:**
- `--scenario normal`: Default realistic drift
- `--scenario low-moisture`: Low soil moisture (<40%), triggers irrigation alert and pump relay ON
- `--scenario high-temp`: Air temperature >38°C, triggers heat stress alert
- `--scenario abnormal-ph`: Extreme soil pH (acidic 4.8 / alkaline 8.4) agronomic advice in Recommendations
- `--scenario pump-cycle`: Alternates pump relay ON/OFF to test pump history timeline and duration
- `--scenario critical`: Combined crisis with low moisture and extreme heat alerts

### 2.3 Start the Alert Worker (optional)

```bash
python tools/alert_worker.py
```

This sends notifications via Telegram or email when problems are detected. See §6 for configuration.

## 3. The Dashboard

Open `http://<pi-ip>:8000` in your browser. The dashboard has two tabs.

### 3.1 Status Bar (top right)

| Indicator | Meaning |
|-----------|---------|
| 🟢 **Live** | Receiving real sensor data from hardware |
| 🟡 **Simulated data (Demo Mode)** | Running software simulator; Field Conditions badge shows `SIMULATED DATA` |
| 🔴 **Waiting…** | No readings received yet |
| 🔴 **Cannot reach server** | Server is not running |

### 3.2 Field Conditions Cards

The top row shows the latest measured or simulated values:
- In demo mode, the card header shows **`SIMULATED DATA`** and the note specifies: *"Synthetic sensor readings generated by the software simulator. No physical sensors connected."*
- When real hardware is connected, the card header shows **`Measured`** and the note confirms: *"All values are measured by on-field sensors. No external weather forecast."*

**Air Conditions (Node 1)**
- Air Temperature (°C)
- Relative Humidity (%)
- Estimated CO₂ (ppm) — derived from MQ-135 sensor
- Soil Moisture (%)
- Water Level (raw ADC value — higher means more water)
- MQ-135 (raw ADC value — higher means more gas)

**Soil Chemistry (Node 2)**
- Soil Temperature (°C)
- Soil Moisture (%)
- pH (soil acidity)
- Nitrogen, Phosphorus, Potassium (units not yet confirmed with hardware team)

**Irrigation (Node 1)**
- All Node 1 values in a table, including pump relay status (On / Off)

Each card shows how recently data was received:
- 🟢 Green = recent (within 2 minutes)
- 🟡 Yellow = getting old
- 🔴 Red = offline (no data for >2 minutes)

### 3.3 Recommendations

The system automatically evaluates the latest readings and provides advice:

| Icon | Level | Meaning |
|------|-------|---------|
| 🚨 | **Critical** | Immediate action required (e.g., soil too dry — irrigate) |
| ⚠️ | **Warning** | Monitor closely (e.g., high temperature — heat stress risk) |
| ✅ | **OK** | All readings within normal range |
| ℹ️ | **Info** | Informational (e.g., nutrient levels need confirmation) |

> **Note:** Nitrogen, Phosphorus and Potassium thresholds are marked as placeholders. Consult an agronomist before acting on NPK recommendations.

### 3.4 Soil Moisture Chart

Shows soil moisture (%) over time for both nodes.

- The **red dashed line** at 40% is the irrigation trigger threshold.
- Use the time filter buttons (**1 Hour, 24 Hours, All**) to zoom in or out.
- The chart auto-refreshes every 5 seconds.

### 3.5 Pump ON/OFF History

Shows when the pump turned on and off, based on the relay state recorded by Node 1.

| Column | Meaning |
|--------|---------|
| ON / OFF badge | Whether the pump switched on or off |
| Timestamp | Date and time of the state change |
| Soil % | Soil moisture at the moment of switching |
| Duration | How long the pump ran (shown on OFF events) |

> This panel only appears when real relay transitions have been recorded. If you are using the simulator, pump events are generated when simulated soil moisture drops below 40%.

## 4. The Alerts Tab

Tap **🔔 Alerts** in the top navigation to see the alert history.

### 4.1 Filters

- **All** — every alert ever recorded
- **Active** — unacknowledged alerts from the last 30 minutes
- **Dismissed** — alerts you have already acknowledged

### 4.2 Dismissing an Alert

Click the **Dismiss** button on any alert row to mark it as acknowledged. This prevents the banner from re-appearing for that alert and clears it from the Active filter.

### 4.3 Alert Banner

When there are unacknowledged critical or warning alerts, a **red banner** appears at the top of the screen. It plays a short audio chime to draw attention.

- **🔔 Mute** — stop the audio (the banner stays visible)
- **✕ Dismiss** — hide the banner (alerts are still in the Alerts tab)
- The banner reappears if **new** alerts are detected on the next refresh.

> **Audio note:** Browsers require a user interaction (tap or click anywhere on the page) before audio can play. If you hear nothing on the first alert, tap the page and the next alert will trigger the sound.

## 5. Installing as a Phone App (PWA)

The dashboard can be installed as a home-screen app on Android or iOS.

**Android (Chrome):**
1. Open `http://<pi-ip>:8000` in Chrome.
2. Tap the **⋮ menu → Add to Home screen**.
3. Tap **Install**.

**iOS (Safari):**
1. Open `http://<pi-ip>:8000` in Safari.
2. Tap the **Share button** (□↑) → **Add to Home Screen**.
3. Tap **Add**.

Once installed, the app works offline for the last-cached version of the dashboard shell. Live sensor data still requires the Raspberry Pi server to be running and reachable on the same Wi-Fi.

## 6. Alert Worker Configuration

The alert worker sends notifications when problems are detected. Set these environment variables before running it:

```bash
# Telegram (optional)
export TELEGRAM_TOKEN="your_bot_token"
export TELEGRAM_CHAT_ID="your_chat_id"

# Gmail (optional)
export GMAIL_USER="your.address@gmail.com"
export GMAIL_APP_PASSWORD="your_app_password"
export ALERT_TO="recipient@example.com"

# Tuning (optional)
export ALERT_COOLDOWN_S=1800   # minimum seconds between repeat alerts (default 30 min)
export ALERT_EVERY_S=20        # check interval (default 20s)
```

If neither Telegram nor Gmail is configured, alerts are only logged to the database (visible in the Alerts tab).

**Security:** Never put API keys or passwords in the code or commit them to the repository.

## 7. Downloading Data

Click **⬇ Download CSV** at the bottom of the dashboard to download up to 2000 recent readings as a CSV file.

Columns: `ts, node, seq, source, air_temp, humidity, soil_moisture, water_raw, mq135_raw, eco2_ppm, relay, soil_temp, ph, n, p, k`

`ts` is a Unix timestamp (seconds since 1970-01-01 UTC). Convert it in spreadsheet software with `=(A2/86400)+DATE(1970,1,1)` (Excel) or `=FROM_UNIXTIME(A2)` (LibreOffice Calc with appropriate add-ins).

## 8. Thresholds and What They Mean

| Parameter | Low Limit | High Limit | Action |
|-----------|-----------|------------|--------|
| Soil Moisture | 40% | 80% | Irrigate below 40%; pause irrigation above 80% |
| Air Temperature | — | 38°C | Heat stress risk — consider shade or ventilation |
| Soil pH | 5.5 | 7.5 | Acidic below 5.5 (consider liming); alkaline above 7.5 |
| Node offline | — | 120 s | No data for >2 min triggers an offline alert |
| Nitrogen | 50 (placeholder) | — | ⚠ Confirm units with hardware team |
| Phosphorus | 20 (placeholder) | — | ⚠ Confirm units with hardware team |

## 9. Troubleshooting

| Problem | Likely Cause | Solution |
|---------|-------------|---------|
| Dashboard shows "Cannot reach server" | Server not running | Run `uvicorn app.main:app --host 0.0.0.0 --port 8000` |
| "Waiting for first reading" for a long time | Data source not started | Start `simulator.py` or `hub_poller.py` |
| Node shows 🔴 offline | No new readings in >2 min | Check the hub power and Wi-Fi; check the hub poller is running |
| Alert banner appears but no sound | Browser audio blocked | Tap anywhere on the page, then wait for the next refresh |
| Pump history empty | No relay state changes recorded | The pump has not switched on/off since the database was created |
| CSV is empty | No data in the database | Start a data source and wait for readings |
